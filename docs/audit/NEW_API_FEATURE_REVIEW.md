# New API 선별 기능 검토

검토 범위는 [New API 공개 README의 기능 목록](https://github.com/QuantumNous/new-api/blob/main/README.md)과 공개 릴리스 설명뿐이다. New API 소스·UI·CSS·문구·이미지·브랜드 자산은 복사하거나 포팅하지 않았다.

New API는 다중 포맷 변환, 지능형 라우팅, 결제·quota 판매, 소셜/OIDC 로그인, 다중 데이터베이스, 다국어 UI를 포함하는 범용 플랫폼이다. LLMWard는 단일 서버·SQLite·100명 이하 내부 조직이라는 더 좁은 목적을 유지한다.

## 라이선스 경계

New API 공개 저장소는 현재 AGPL-3.0과 추가 조건을 명시한다. LLMWard의 MIT 라이선스 유지는 독립 구현이고 New API 코드·UI·자산의 파생물이 아니라는 전제에서만 정합적이다. 이번 작업은 공개 기능 흐름만 비교했고 저장소에 New API 코드를 가져오지 않았다. 법적 결론은 아니므로 공개 릴리스 전 저작권자와 구현 provenance를 프로젝트 관리자가 확인해야 한다.
